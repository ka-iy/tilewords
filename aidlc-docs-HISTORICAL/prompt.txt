INITIAL PROMPT
-------------------------------
Using AI-DLC, write a scrabble game using the Go programming language and which runs on multiple platforms including mobile devices. The game should use proper graphical elements like https://github.com/apikler/ScrabbleAI does. Use the 1998 paper by Appel and Jacobson, titled "The World's Fastest Scrabble Program" to implement the game engine. The game should allow a human to play against the computer with varying and selectable levels of profiency for the computer player. A computer player at level 1 should be very weak and a computer player at level 10 should always pick the most optimum word which is valid and which yields the maximum possible score. Allow the user to select from various dictionaries to use for checking words, such as Collins Scrabble Words, SOWPODS, OSPD, NASPA, OTCWL, or a combination of all the preceding dictionaries. When constructing the word list for the game engine, eliminate duplicate words if multiple dictionaries are selected. Disallow bluffing.
